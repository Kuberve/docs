# Kuberve Documentation

Документация проекта Kuberve: архитектура, гайды, журнал разработки.

**Статус:** pre-alpha, ABI нестабилен, всё меняется.

## Разделы

- [ROADMAP.md](ROADMAP.md) — план развития, вехи, критерии готовности
- [architecture/overview.md](architecture/overview.md) — что такое Kuberve, из каких частей состоит
- [guides/](guides/) — как собрать, как писать программы (по мере появления)
- [devlog/](devlog/) — журнал разработки, что сделано и когда

## Связанные репозитории

- `Kuberve/kernel` — ядро
- `Kuberve/libc` — userspace-библиотека
- `Kuberve/abi` — общие типы (Message, syscall номера)
- `Kuberve/user` — userspace-программы
- `Kuberve/spec` — формальные спецификации ABI

## Для кого

- Автор (чтобы через полгода вспомнить, что как устроено)
- Будущие контрибьюторы
- Себя-через-год, когда проект станет больше
